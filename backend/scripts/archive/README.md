# Archived Backend Scripts

This folder contains one-off or legacy backend scripts that are not part of the current main runtime or documented operational flow.

Archived here to keep the repo tidy without deleting potentially useful historical utilities.

Current archive contents include:
- legacy migration helpers
- one-off verification helpers
- sample generation helpers not used by the main dev/runtime flow

Before reusing one of these scripts, review it against the current data model and runtime assumptions.
