# Backlog

Đặt các ticket refactor ở đây.

Khuyến nghị:

- một ticket = một seam hoặc một slice nhỏ
- không gộp quá nhiều mục tiêu vào một ticket
- nếu ticket chạm cả backend + frontend + contract, cân nhắc tách thành:
  - backend ticket
  - frontend ticket
  - cross-cutting coordination ticket

Mỗi ticket nên bám theo template trong `tickets/templates/refactor-ticket.md`.
